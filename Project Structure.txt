1. PROJECT NAME AND PURPOSE
- Name: AQUILOOP (Hero Feature: MONSOONLOOP)
- Purpose: Turn rainfall, waste, and crop residue into local climate action.
- Final Three-Feature Product Architecture:
  1. MONSOONLOOP — Rain -> Action -> Recharge (`/monsoonloop`):
     - Description: "Turn rainfall forecasts into pre-storm action."
     - CTA: `OPEN MONSOONLOOP`
     - Operator View (`OPERATOR` Cognito group only):
       - Compact Delhi/NCR Zone Selector (`Delhi`, `Mayapuri`, `Najafgarh`, `Dwarka`, `Rohini`, `Bawana`, `Okhla`, `Narela`) with live Open-Meteo peak rainfall (`mm/hr`), 72h total (`mm`), and ambient temperature (`°C`).
       - Real Open-Meteo Rainfall Graph (`"When will rainfall peak?"` with 72-hour hourly forecast curve, explicit `Configured drainage capacity: X mm/hr` threshold line, `Source: Open-Meteo`, `Last updated` timestamp, and Operator-only `Refresh Weather` button).
       - Simplified Deterministic Risk Panel (`"Why is this zone risky?"` with Risk Level, Risk Score, and Top 3 Contributing Factors derived deterministically from real peak rainfall, rain probability, rain persistence hours, configured drainage capacity, and drain/asset inspection state).
       - Decision-Oriented Geographic Map (`"Where is the problem & what action is needed?"` with Carto Dark Matter basemap + Delhi roads/waterways overlay, RED blocked drains, GREEN water assets, BLUE active tasks, YELLOW candidate sites, live rainfall intensity status, and compact selected marker detail panel with `Create Bounty` / `Dispatch Task`).
       - Top 3 Recommended Actions (`Dispatch Task` / `Create Bounty` scaled deterministically from real forecast severity).
       - Dispatched Tasks & Operator Verification (`Approve` / `Request Rework` for submitted tasks).
       - Simplified Task Result (`Tasks Completed`, `Verification Status`, `Estimated Water Benefit`).
     - Worker View (`WORKER` Cognito group only):
       - Mobile-first field app (`MY TASK` -> `START TASK` -> `1. Before Photo` -> `2. Do the Work` -> `3. After Photo` -> `4. Location` -> `5. Submit Evidence` -> `Submitted for verification · Status: Pending Review`).
  2. FLOOD & WASTE BOUNTIES — Find -> Cleanup -> Verify (`/flood-bounties`):
     - Description: "Turn blocked-drain waste into verified cleanup work."
     - CTA: `OPEN FLOOD BOUNTIES`
     - Operator View (`OPERATOR` Cognito group only: `CREATE -> MONITOR -> VERIFY -> APPROVE`):
       - Top Summary Strip (`Open Bounties`, `Active Bounties`, `Pending Verification`, `Completed / Verified`).
       - `Create Bounty` form drawer.
       - `Pending Verification List` (`Bounty ID`, `Worker`, `Location`, `Task`, `Status`, `[Review]`) opening a dedicated **Evidence Review Modal** (`BEFORE` vs `AFTER` real S3 signed-URL comparison, **Amazon Bedrock AI Evidence Check Panel** (`Run AI Check` / `Retry AI Check`, `Overall Assessment`, `Confidence`, `Task Match`, `Before Evidence`, `After Evidence`, `Consistency`, `Observations`, `Concerns`, explicit `AI Assessment` vs `Operator Decision` separation), and final `APPROVE` / `REJECT` controls).
       - `Bounty Board & Delhi Map` where every bounty is its own independent card with a working `[Inspect Bounty]` button opening the **Inspect Bounty Modal** (with real S3 evidence preview).
       - Compact `Cleanup Outcome Summary` (`Cleanup verified`, `Waste cleared`, `ARC issued`).
     - Worker View (`WORKER` Cognito group only):
       - Mobile-first field-task workflow (`FIND -> CLAIM -> START -> 1. Before Photo (S3) -> 2. Cleanup -> 3. After Photo (S3) -> 4. Location -> 5. Submit Evidence -> Submitted for verification · Status: Pending Review` + read-only `AI check: Completed` / `AI check: Pending review` status badge).
  3. STUBBLE-TO-WATER EXCHANGE — List -> Pickup -> Verify (`/stubble-exchange`):
     - Description: "Connect crop residue with local buyers."
     - CTA: `OPEN STUBBLE EXCHANGE`
     - Farmer View (`FARMER` Cognito group only):
       - `My Listings`, `+ List Stubble`, `Pickup Status` (`Listed -> Accepted -> Scheduled -> Picked Up -> Verified`), `ARC Earned`, `ARC Pending`.
     - Buyer View (`BUYER` Cognito group only):
       - Left side: `Available Listings`
       - Right side: **Selected Listing Only** (`SELECTED LISTING · STB #DL-019`) with unified step-by-step pickup workflow (`OPEN -> Accept Pickup`, `ACCEPTED -> Schedule Pickup`, `SCHEDULED -> Start Pickup`, `IN_TRANSIT -> Mark Picked Up`, `PICKED_UP -> Submit Pickup Proof (S3)`, `PENDING_VERIFICATION -> Submitted for verification · Pending Operator Review`, `VERIFIED -> Completed`).
     - Operator View (`OPERATOR` Cognito group only):
       - `Pending Verification` queue, `Transaction Review` (with real S3 pickup proof image loaded via signed URL, **Amazon Bedrock AI Evidence Check Panel**, and `Approve` / `Reject` with structured reason), `Exchange Outcome Summary`, and ONE recovery chart (`"How much stubble is being recovered?"`).

2. CURRENT ARCHITECTURE
- Next.js 15 (App Router) + TypeScript + AWS Amplify Gen 2 (`ap-southeast-2`).
- Authoritative Amazon Cognito Authentication & Role-Based Access Control:
  - Cognito User Pool (`ap-southeast-2_KeMxKqPnR`) with four User Pool Groups: `OPERATOR`, `WORKER`, `FARMER`, `BUYER`.
  - Unauthenticated requests are gated at `<AppShell>` by `<AquiloopAuthScreen>` with zero flash of protected content.
  - Application role is derived strictly from the authenticated user's Cognito JWT token (`cognito:groups` claim) via `useCurrentRole()`.
  - Public self-registration allows `WORKER`, `FARMER`, and `BUYER` onboarding via `POST /api/auth/assign-role`; `OPERATOR` self-assignment is strictly blocked (`403 Forbidden`) and requires Cognito `OPERATOR` group membership.
- Real Persistent AWS AppSync + Amazon DynamoDB Data Layer (`amplify/data/resource.ts`):
  - GraphQL Endpoint: `https://hgo56oow65ctjhy7m3qotfdxc4.appsync-api.ap-southeast-2.amazonaws.com/graphql` (default auth: `userPool`).
  - Six DynamoDB Models with strict model-level and field-level Cognito group/owner authorization:
    1. `Task` (`Task-6d3ozvmhmvfpxlaayhb66d4oli-NONE`)
    2. `Bounty` (`Bounty-6d3ozvmhmvfpxlaayhb66d4oli-NONE`)
    3. `StubbleListing` (`StubbleListing-6d3ozvmhmvfpxlaayhb66d4oli-NONE`)
    4. `UserProfile` (`UserProfile-6d3ozvmhmvfpxlaayhb66d4oli-NONE`)
    5. `WeatherForecast` (`WeatherForecast-6d3ozvmhmvfpxlaayhb66d4oli-NONE` with GSI `weatherForecastsByLocationKeyAndForecastTime` / queryField `listWeatherByLocationAndTime`)
    6. `EvidenceVerification` (`EvidenceVerification-6d3ozvmhmvfpxlaayhb66d4oli-NONE` with GSI `evidenceVerificationsByResourceIdAndEvaluatedAt` / queryField `listVerificationsByResource`; `allow.group("OPERATOR")` full CRUD, `allow.ownerDefinedIn("ownerId").to(["read"])`)
- Real Server-Side Amazon Bedrock AI Evidence Verification Pipeline (`amplify/functions/verify-evidence/`):
  - AWS Lambda Function: `amplify-aquiloop-KrrishCh-verifyevidencelambdaD1E1-CxeD3JYiJ34W` (`nodejs22.x`, `60s` timeout, `512 MB` memory).
  - AppSync Custom Mutation: `verifyEvidence` (`allow.group("OPERATOR")`).
  - Multimodal AI Model: Amazon Bedrock Runtime `ConverseCommand` with `amazon.nova-lite-v1:0` (and fallback chain `apac.amazon.nova-lite-v1:0`, `amazon.nova-pro-v1:0`, `apac.amazon.nova-pro-v1:0`) in `ap-southeast-2`.
  - Cost Control & Idempotency: Keyed by `id = "${evidenceType}#${resourceId}#${sha256(evidenceFingerprint).slice(0, 16)}"` so unchanged evidence returns the persisted verification without duplicate Bedrock calls unless `forceRecheck: true`.
  - Assistive & Safe: Malformed/incomplete model JSON safely defaults to `NEEDS_REVIEW` (`confidence: 0`); Bedrock unavailability returns an honest human-readable message without fabricating a fake result; AI never auto-approves or auto-rejects.
- Real Server-Side Weather Ingestion Pipeline (`amplify/functions/weather-ingest/`):
  - AWS Lambda Function: `amplify-aquiloop-KrrishCh-weatheringestlambda6F792-xNVobospdmap` (`nodejs22.x`, `60s` timeout, `512 MB` memory).
  - Scheduled Execution: Amazon EventBridge Schedule `amplify-aquiloop-KrrishCh-weatheringestlambdasched-5W3DOAR06IY9` (`every 3h`, `ENABLED`).
  - On-Demand Operator Execution: AppSync custom mutation `refreshWeatherForecast` (`allow.group("OPERATOR")`).
  - Weather Source: Open-Meteo Forecast API (`https://api.open-meteo.com/v1/forecast`, 72-hour hourly `precipitation`, `precipitation_probability`, `temperature_2m`, `weather_code`, `timezone=Asia/Kolkata`).
- Real Private Amazon S3 Evidence Storage (`amplify/storage/resource.ts`):
  - S3 Bucket: `amplify-aquiloop-krrishch-aquiloopevidencestorageb-sfreg9gsjgdi` (`ap-southeast-2`).
  - Private bucket with Cognito group-scoped IAM policies (`bounties/*`, `stubble/*`, `tasks/*`) and Lambda IAM read access for server-side Bedrock inspection.
- Direct AQUILOOP Home Load (`/` -> `src/app/page.tsx` -> `src/components/home/aquiloop-home.tsx`).
- Zero Standalone Dashboards or Ledgers:
  - No `Command Center`, `Missions`, `RainBank`, `Impact`, `ARC Ledger`, or `Resilience Credit Ledger` anywhere in the application.
